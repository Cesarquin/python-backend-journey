# Python 101

Este módulo reúne los materiales y ejercicios desarrollados durante la enseñanza de un curso de fundamentos de Python.

El contenido refleja una progresión práctica por los principales conceptos del lenguaje, desde las instrucciones básicas y el manejo de datos hasta estructuras de control, funciones, colecciones y programación orientada a objetos.

## Contenido

En este módulo se trabajan, entre otros, los siguientes temas:

* Sintaxis y fundamentos de Python.
* Variables y tipos de datos.
* Entrada y salida de información.
* Operadores.
* Estructuras condicionales.
* Ciclos.
* Funciones y módulos.
* Colecciones.
* Programación orientada a objetos.
* Introducción a librerías externas.

## Organización

El contenido se incorpora progresivamente al repositorio y se organiza por temas para facilitar su consulta y mantener una estructura clara.

## Propósito del repositorio

Este material forma parte de un proceso de organización y evolución de contenidos y código desarrollados en el contexto de la enseñanza de Python, incorporando prácticas de organización, documentación y control de versiones con Git y GitHub.
